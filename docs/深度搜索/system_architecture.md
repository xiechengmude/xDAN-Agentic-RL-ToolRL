# xDAN-DeepResearch 问题生成与轨迹生成系统架构

## 系统概述

xDAN-DeepResearch 系统设计了一个完整的问题生成和轨迹生成流程，用于训练和评估搜索智能体的多方面能力。该系统采用模块化设计，首先使用不同的生成脚本创建各种类型的问题，然后使用轨迹生成器基于这些问题生成搜索轨迹。

## 系统架构

### 1. 问题生成模块

系统包含8种主要的问题生成模式：

#### 1.1 基础问题生成
- `generate_questions.py` - 基础问题生成脚本
- `generate_questions_fixed.py` - 修复版基础问题生成脚本
- `generate_questions_enhanced.py` - 增强版问题生成脚本

#### 1.2 领域特定问题生成（7种专业领域）
1. **数据分析类** (`generate_enhanced_data_analysis.py`)
   - 生成与数据分析、统计、可视化相关的问题
   - 例如：财报分析、数据趋势分析、复合增长率计算等

2. **文献分析类** (`generate_enhanced_literature.py`, `generate_enhanced_literature_fixed.py`)
   - 生成与学术文献综述、研究分析相关的问题
   - 例如：特定领域的文献综述、研究方法比较、跨学科应用分析等

3. **长尾搜索类** (`generate_enhanced_long_tail.py`)
   - 生成针对小众内容、难以检索信息的问题
   - 例如：古文明研究、特定历史事件、罕见现象等

4. **市场研究类** (`generate_enhanced_market.py`)
   - 生成与市场分析、产品评估、行业趋势相关的问题
   - 例如：产品市场分析、竞争对手分析、市场细分研究等

5. **编程类** (`generate_enhanced_programming.py`)
   - 生成与编程、软件开发、系统设计相关的问题
   - 例如：算法实现、系统架构设计、代码优化等

6. **旅游规划类** (`generate_enhanced_travel.py`)
   - 生成与旅行规划、行程安排相关的问题
   - 例如：多地旅游路线规划、预算控制、特定兴趣点推荐等

7. **其他专业领域**
   - 系统设计允许扩展更多专业领域的问题生成模块

### 2. 基础框架

`generate_enhanced_base.py` 提供了增强版问题生成的基础框架，包含：

- **设计意图** (target)：明确定义每个问题的目标和测试重点
- **验收标准** (verify)：定义评估问题回答质量的标准和维度
- **问题结构模板**：确保生成的问题具有一致的格式和质量
- **评分指南**：提供对回答质量的量化评估方法

### 3. 轨迹生成模块

- `run_generation.py` - 运行基础轨迹生成
- `run_enhanced_trace_generator.py` - 运行增强版轨迹生成器
- `run_question_generator.py` - 运行问题生成器

轨迹生成器基于生成的问题，模拟搜索智能体的搜索过程，记录完整的交互轨迹，包括：

- 问题分解
- 搜索查询生成
- 搜索结果分析
- 内容获取决策
- 多轮交互过程
- 最终答案生成

## 系统工作流程

1. **问题生成阶段**
   - 使用领域特定的生成脚本创建各类问题
   - 每个问题包含明确的设计意图和验收标准
   - 生成的问题保存为JSON格式

2. **轨迹生成阶段**
   - 轨迹生成器读取问题文件
   - 为每个问题生成完整的搜索轨迹
   - 轨迹包含5-10轮交互，模拟真实搜索过程
   - 生成的轨迹保存为JSON格式

3. **评估与训练阶段**
   - 使用生成的轨迹评估搜索智能体性能
   - 轨迹可用于监督微调(SFT)训练搜索智能体

## 系统特点

1. **模块化设计**：各组件独立开发，易于扩展和维护
2. **多领域覆盖**：涵盖多种专业领域，全面测试智能体能力
3. **质量保证**：每种问题类型都有明确的验收标准
4. **可扩展性**：可轻松添加新的问题类型和领域
5. **真实模拟**：轨迹生成过程模拟真实用户搜索行为

## 应用场景

该系统主要用于：

1. 生成高质量的训练数据，用于搜索智能体的监督微调
2. 评估搜索智能体在不同领域的性能
3. 测试搜索智能体的多轮交互能力
4. 验证搜索智能体的工具调用能力
5. 分析搜索智能体的决策过程

通过这个系统，可以全面提升搜索智能体的能力，使其能够进行复杂搜索任务，并提供高质量的搜索体验。

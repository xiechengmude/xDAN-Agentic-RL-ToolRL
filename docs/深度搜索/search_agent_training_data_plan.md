# 原生搜索智能体训练数据生成计划

## 一、设计背景与目标

原生搜索智能体需要通过监督微调（SFT）掌握高质量的动态工具调用能力，能够根据工具返回的结果进行思考、分析和判断，并自主决策下一步动作。为了实现这一目标，我们需要生成高质量、多样化的训练数据集，覆盖各种搜索场景和能力维度。

本计划旨在：
1. 设计全面的场景覆盖方案，确保训练数据的多样性和代表性
2. 明确各能力维度的分布比例，平衡不同类型问题的数量
3. 提供具体的实施策略，包括批量生成和质量控制机制
4. 为后续优化提供方向指导

## 二、核心能力维度与场景分布

基于问题生成策略文档，我们需要覆盖以下11大核心能力维度，每个维度下设置多个具体场景：

### 1. 日常搜索能力（占比20%）
- **健康与医疗咨询**：常见疾病、健康生活方式、医疗资源查询
- **家居维修与装修**：家电维修、装修材料、居家技巧
- **娱乐与休闲活动**：电影推荐、旅游景点、本地活动
- **教育与学习资源**：在线课程、学习方法、教育机构
- **消费决策与产品比较**：电子产品、日用品、服务评价

### 2. 在线检索能力：小众内容定位（占比10%）
- **冷门电影和文化作品检索**：小众导演作品、非主流艺术流派
- **学术论文和专业出版物查找**：特定领域研究、历史文献
- **新发布书籍和媒体内容**：近期出版物、新兴媒体平台
- **传统工艺和非主流知识领域**：地方传统技艺、小众爱好知识

### 3. 数据分析能力：财务与数据计算（占比10%）
- **企业财务报表分析**：毛利率分析、资产负债评估
- **增长率和效率指标计算**：研发支出比较、生产效率计算
- **跨期和跨企业比较分析**：季度业绩对比、行业标杆分析
- **财务预测和趋势识别**：销售预测、库存周转率分析

### 4. 编程能力：智慧城市设计（占比10%）
- **智能农业监控系统设计**：传感器网络、数据分析算法
- **碳足迹追踪平台开发**：排放计算、可视化展示
- **远程医疗解决方案规划**：数据安全、实时通信
- **智能垃圾分类系统构建**：图像识别、物联网集成

### 5. 文献分析能力：多话题科研综述（占比10%）
- **AI伦理与监管研究综述**：法规发展、伦理框架
- **区块链技术应用现状分析**：金融应用、供应链管理
- **远程工作对心理健康影响研究**：工作效率、社交隔离
- **跨学科领域发展趋势分析**：生物信息学、计算社会科学

### 6. 路线设计能力：旅游方案规划（占比10%）
- **三代同堂家庭旅行规划**：适老适幼景点、行程节奏
- **特定预算下的自驾游设计**：路线优化、成本控制
- **文化体验与美食探索结合**：地方特色、文化活动
- **特殊需求人群的旅行安排**：无障碍设施、医疗保障

### 7. 报告输出能力：研报分析（占比10%）
- **新兴市场机会分析**：市场规模、进入策略
- **产品竞争力评估**：SWOT分析、市场定位
- **行业发展趋势预测**：技术演进、消费模式
- **消费者行为研究**：购买决策、品牌忠诚度

### 8. 多模态信息整合能力（占比5%）
- **基于图表和数据可视化的经济趋势分析**：图表解读、数据关联
- **结合视频内容的教育资源评估**：视频质量、内容深度
- **音频转录与文本资料结合的历史研究**：口述历史、文献比对
- **图像识别与文献检索结合的艺术品分析**：风格鉴定、历史溯源

### 9. 多语言跨文化检索能力（占比5%）
- **多语言文献的综合研究**：跨语言资源整合、翻译准确性
- **跨国市场比较分析**：区域差异、文化适应
- **国际法规和政策研究**：法律体系比较、政策影响
- **全球文化现象的比较研究**：文化符号、社会背景

### 10. 时间敏感信息追踪能力（占比5%）
- **实时事件进展追踪**：突发事件、动态更新
- **政策变更影响分析**：法规调整、市场反应
- **市场波动原因溯源**：价格变动、供需关系
- **科技发展时间线构建**：技术演进、里程碑事件

### 11. 争议性话题分析能力（占比5%）
- **社会政治争议分析**：多方立场、政策辩论
- **科学争论综述**：理论冲突、实验证据
- **伦理道德两难问题研究**：价值观冲突、决策框架
- **多方利益相关者观点整合**：利益平衡、共识构建

## 四、问题结构设计

每个生成的问题都应包含以下要素：

### 1. 基本结构
- **问题ID**：唯一标识符，格式为"类别_时间戳_序号"
- **类别**：所属能力维度
- **问题文本**：详细的问题描述和要求
- **设计意图(target)**：明确说明问题的目标和测试重点
- **验收标准(verify)**：包含评分指南和评估维度

### 2. 验收标准详细结构
- **评分指南**：统一的评分标准和方法
- **评估维度**：3-5个关键评估维度
- **维度描述**：每个维度的详细解释
- **评分标准**：1-5分的详细评分标准

### 3. 示例格式
```json
{
  "id": "everyday_1234567890_0",
  "category": "日常搜索：健康与医疗咨询",
  "question": "如何缓解季节性过敏症状？有哪些非药物治疗方法？",
  "target": "这个问题测试搜索智能体在健康医疗领域的信息检索和综合分析能力...",
  "verify": {
    "scoring_guide": "每个维度按1-5分评分，1分为不满足要求，5分为卓越表现...",
    "evaluation_dimensions": {
      "信息准确性": {
        "description": "回答中提供的医疗信息是否准确、可靠",
        "scoring_criteria": {
          "1分": "信息严重错误或完全不相关",
          "2分": "信息部分准确，但有明显错误",
          "3分": "信息基本准确，可能有小错误",
          "4分": "信息准确，来源可靠",
          "5分": "信息完全准确，并有权威医学来源支持"
        }
      },
      // 其他评估维度...
    }
  }
}
```

## 五、实施方案

### 1. 分批生成策略
- **批次划分**：考虑到API调用限制和稳定性，建议分10批次生成，每批次100条
- **批次平衡**：每批次包含不同能力维度的问题，保持整体分布比例
- **执行周期**：每批次生成后进行质量检查，确认无问题后再进行下一批次

### 2. 质量控制机制
- **随机抽样检查**：每批次随机抽取10%的问题进行人工审核
- **多样性检查**：确保问题覆盖不同难度级别和领域
- **一致性验证**：确保评估标准的一致性和公平性
- **可行性测试**：抽样测试问题的可回答性
- **重复性检查**：避免生成过于相似的问题

### 3. 执行流程
1. 准备环境和依赖
2. 配置API密钥和参数
3. 执行批量生成脚本
4. 质量检查和问题筛选
5. 合并最终数据集
6. 数据集验证和备份

## 六、后续优化方向

### 1. 短期优化
- **问题质量评估**：对生成的问题进行人工评估，筛选出高质量问题
- **问题难度分级**：将问题按难度分为初级、中级和高级
- **提示词优化**：根据生成结果反馈调整LLM提示词，提高问题质量

### 2. 中长期优化
- **场景扩展**：根据实际需求扩展更多场景和能力维度
- **自适应生成**：根据智能体表现动态调整问题难度和类型
- **用户反馈整合**：收集真实用户反馈改进问题质量
- **评估框架优化**：完善评估标准和方法
- **多智能体协作场景**：设计需要多个智能体协作解决的复杂问题

## 七、预期成果

通过本计划的实施，我们预期获得以下成果：

1. 一个包含1000条高质量问题的训练数据集
2. 覆盖11个核心能力维度的全面问题库
3. 每个问题都配有详细的设计意图和评估标准
4. 可用于原生搜索智能体训练和评估的结构化数据

这个全面的训练数据生成计划将确保我们能够训练出具备高质量动态工具调用能力、自主决策能力和深度搜索能力的原生搜索智能体。

## 代表性场景横向对比

下表展示了10个代表性金融场景下，不同系统的表现对比，帮助您更直观地理解各类系统的优势与局限。

### 场景1：新手投资指导

| 系统/产品 | 表现与处理方式 |
|----------|--------------|
| **通用金融智能体 (xDAN Hermes Agent)** | 通过多轮对话了解用户背景、财务状况和目标，提供个性化入门教育内容，解释基础概念，推荐适合新手的低风险投资策略，持续跟进学习进度和投资表现。 |
| **通用智能体 (General Agent)** | 推荐入门投资书籍和文章，解释基本概念，但缺乏深度金融知识和个性化建议能力，无法根据市场变化提供动态指导。 |
| **大模型 (LLM)** | 可提供基础投资知识解释和概念澄清，但信息可能过时，且无法根据用户特定情况提供个性化建议，也无法访问实时市场数据。 |
| **Workflow Agent** | 仅能执行预设的新手引导流程，如发送标准化的入门材料包或触发预定的培训课程，缺乏交互性和个性化。 |
| **传统金融产品 (Wind, Bloomberg)** | 提供全面但复杂的市场数据和分析工具，对新手极不友好，学习曲线陡峭，通常需要专业培训才能有效使用。 |

**使用方式示例：**

| 系统/产品 | 使用方式示例 |
|----------|------------|
| **通用金融智能体 (xDAN Hermes Agent)** | 用户："我是投资新手，有10万元储蓄，想开始投资但不知从何入手。"<br>智能体首先询问用户年龄、收入状况、财务目标和风险偏好，然后回应："根据您27岁、稳定工作、中等风险偏好的情况，建议您先建立3-6个月应急基金，然后可以考虑这样的初始配置：**60%指数基金(推荐沪深300和纳斯达克100各半)、30%国债或AAA级债券基金、10%货币市场基金**。我准备了投资入门指南和每个推荐产品的详细解析，您想先了解哪部分？另外，我可以为您制定6个月的学习路径，循序渐进地掌握投资知识。" |
| **通用智能体 (General Agent)** | 用户："我是投资新手，怎么开始投资？"<br>智能体："作为新手，您可以考虑从以下几步开始：1)了解基础知识，推荐《小狗钱钱》和《指数基金投资指南》；2)考虑先投资ETF或指数基金，分散风险；3)坚持长期投资和定投策略。您可能需要开设证券账户，主流券商有招商、华泰等。投资前请确保有充足的应急资金。" |
| **大模型 (LLM)** | 用户："新手如何开始投资？"<br>LLM："投资新手可以从以下步骤开始：首先，建立个人财务基础，包括预算规划和应急基金；其次，了解基本投资概念如复利、分散投资和长期投资；然后，可以考虑低成本指数基金作为起点；最后，随着知识增长逐步拓展投资范围。记住，投资需要耐心和持续学习，不要追求快速致富。" |
| **Workflow Agent** | 用户在投资平台注册后，系统自动触发"新手引导"流程：用户收到标准化欢迎邮件："感谢加入我们的投资平台！为帮助您开始投资旅程，我们已为您准备了新手入门包。"随后系统定期发送预设的系列邮件，包括"投资基础知识"、"如何选择第一支股票"等通用内容，所有用户收到相同材料，没有个性化调整。 |
| **传统金融产品 (Bloomberg)** | 新用户登录Bloomberg终端面对复杂界面，需阅读厚重的用户手册或参加付费培训课程。用户可能尝试使用基本功能如股票查询(输入代码后按EQUITY<GO>)，但无引导帮助理解数据含义；查看基础分析需要知道专业功能代码如FA<GO>(财务分析)、GP<GO>(图表)等。用户通常需要数周时间自学或专业培训才能基本操作，很少有新手能独立有效使用。 |

### 场景2：市场异常波动应对（实时财经分析师）

| 系统/产品 | 表现与处理方式 |
|----------|--------------|
| **通用金融智能体 (xDAN Hermes Agent)** | 检测到市场异常波动时主动提醒用户，分析波动原因及历史类似情况，根据用户投资组合评估影响，提供多种应对策略选项并解释各自的风险和潜在结果。 |
| **通用智能体 (General Agent)** | 可在用户询问时提供基本市场新闻摘要，但难以进行深度分析或提供针对性建议，无法评估具体投资组合的风险暴露。 |
| **大模型 (LLM)** | 能够解释已知的市场事件概念和历史案例，但缺乏实时数据，无法分析当前具体情况或提供及时建议。 |
| **Workflow Agent** | 可能执行预设的市场波动应急流程，如发送标准化警报或执行预定的对冲指令，但缺乏灵活性和个性化分析能力。 |
| **传统金融产品 (Wind, Bloomberg)** | 提供全面的市场数据和异常监测，强大的技术分析工具和历史对比功能，但需要用户自己解读数据并决策，不提供主动建议。 |

**使用方式示例：**

| 系统/产品 | 使用方式示例 |
|----------|------------|
| **通用金融智能体 (xDAN Hermes Agent)** | 用户收到主动推送通知：**"检测到市场异常波动：道琼斯指数今日下跌3.2%，VIX飙升42%。"<br>**用户点击查看详情，智能体分析："此次下跌主要由美联储鹰派言论和**地缘政治紧张**加剧引起。分析您的投资组合：预计短期波动可能导致3-5%回撤，其中科技股敞口(占比38%)风险最高。考虑到您的长期目标和上次对话中确认的风险承受能力，建议：1)保持冷静，这类波动在历史上平均持续10-14天；2)可考虑利用波动为部分优质股加仓(详细名单见附件)；3)或临时增加5-10%现金仓位作为缓冲。您希望我分析哪个选项的详细执行步骤？" |
| **通用智能体 (General Agent)** | 用户："市场今天大跌，我应该怎么办？"<br>智能体："据报道，市场确实出现大幅下跌。一般来说，市场波动是正常的，长期投资者应避免恐慌性决策。您可以回顾自己的投资计划，确保资产配置符合风险承受能力。如果您担心进一步下跌，可以考虑分散投资或增加现金比例。最新消息显示，此次下跌可能与利率政策和经济数据有关。" |
| **大模型 (LLM)** | 用户："市场崩盘时应该怎么做？"<br>LLM："市场大幅下跌时，建议采取以下策略：首先，保持冷静，避免恐慌性决策；其次，重新评估您的投资组合是否符合长期目标；第三，考虑这可能是优质资产的买入机会；第四，确保有足够的应急资金不受市场波动影响。历史表明，市场长期向上，许多投资者通过在波动期保持耐心而受益。1987年'黑色星期一'和2008年金融危机后的市场表现都印证了这一点。" |
| **Workflow Agent** | 当市场波动超过预设阈值(如VIX上涨>30%)，系统自动向所有客户发送标准化邮件："市场波动提示：我们注意到市场出现明显波动。根据您的风险等级(保守型/平衡型/进取型)，建议您参考我们的标准应对方案(附件)。如需调整投资，请登录平台或联系客户经理。"邮件附件包含三种预设风险级别的通用建议，无个性化内容。 |
| **传统金融产品 (Bloomberg)** | 用户登录Bloomberg终端，可在主页看到市场异常指标闪烁。需要**用户主动使用多个功能进行分析**：先使用NEWS<GO>查看最新消息，再使用WEI<GO>查看经济指标影响，然后用PREP<GO>分析历史类似事件模式，最后需要使用PORT<GO>自行分析组合风险敞口并手动计算可能影响。所有数据和分析工具完备，但需要用户具备专业知识来解读数据和制定应对策略。 |

### 场景3：投资组合优化

| 系统/产品 | 表现与处理方式 |
|----------|--------------|
| **通用金融智能体 (xDAN Hermes Agent)** | 全面分析当前投资组合的资产配置、风险暴露和历史表现，**考虑用户目标和市场预期**，生成多个优化方案并解释每个方案的优劣势，协助用户选择并实施最佳方案。 |
| **通用智能体 (General Agent)** | 理解基本投资组合理论并提供一般性建议，如"增加多样化"，但难以进行具体数量分析或考虑复杂因素如税务影响、风险偏好等。 |
| **大模型 (LLM)** | 能够解释投资组合理论和常见优化策略，但无法分析具体投资组合数据或执行优化计算，建议停留在理论层面。 |
| **Workflow Agent** | 可能执行标准化的组合再平衡流程，如根据预设规则调整偏离的资产比例，但缺乏创造性优化和市场适应性。 |
| **传统金融产品 (Wind, Bloomberg)** | 提供强大的组合分析和优化工具，支持各类复杂模型和情景测试，但需要专业知识操作，**不提供直观解释或自动化建议**。 |

**使用方式示例：**

| 系统/产品 | 使用方式示例 |
|----------|------------|
| **通用金融智能体 (xDAN Hermes Agent)** | 用户："我的投资组合表现感觉一般，能帮我优化提高收益吗？"<br>智能体首先分析用户现有组合："您目前的投资组合年化收益率6.5%，波动率18%，夏普比率0.32，低于市场平均水平。主要问题包括：1)大盘股与小盘股比例不均(82/18)；2)美国市场过度集中(占比76%)；3)债券久期不匹配(平均久期7年对应您5年目标)；4)部分基金费率过高(平均0.82%)。"<br>随后提供三套优化方案："方案A:稳健优化-调整资产配置至60/30/10(股/债/另类),预期提升夏普比率至0.41；方案B:积极优化-增加新兴市场敞口和价值股比重,预期回报提升1.2%但波动增加；方案C:费用优化-替换6只高费基金为同类低费ETF,每年节省0.4%费用。"同时展示每个方案的模拟回测结果、预期收益和风险指标对比图表，并解释："根据您此前表达的退休目标和风险承受能力，推荐方案A，可逐步分3个月实施以降低市场时点风险。需要我详细解释实施步骤吗？" |
| **通用智能体 (General Agent)** | 用户："如何优化我的投资组合？"<br>智能体："优化投资组合通常需要考虑以下几点：1)确保充分多元化，横跨不同行业和地区；2)检查资产配置是否符合您的风险承受能力和投资期限；3)定期再平衡，保持目标配置；4)留意费用，尽量选择低成本基金；5)考虑税务效率，合理利用免税账户。如果您能分享当前投资组合的具体构成，我可以提供更有针对性的建议。" |
